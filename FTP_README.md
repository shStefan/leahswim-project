# FTP Сервер - Инструкция

FTP сервер успешно настроен на удаленном сервере.

## Информация о сервере

- **Хост:** 51.250.97.231
- **Порт:** 21
- **Режим:** Пассивный (PASV)
- **Пассивные порты:** 40000-50000

## Создание FTP пользователя

Для создания нового FTP пользователя используйте скрипт:

```bash
./create-ftp-user.sh <имя_пользователя>
```

Пример:
```bash
./create-ftp-user.sh yandex
```

Или вручную на сервере:
```bash
ssh -i ~/.ssh/mainkey main@51.250.97.231
sudo useradd -m -d /home/yandex -s /bin/bash yandex
sudo passwd yandex
sudo chmod 755 /home/yandex
```

## Настройка файрвола облачного провайдера

**ВАЖНО:** Убедитесь, что в панели управления Yandex Cloud открыты следующие порты:

1. **Порт 21 (TCP)** - управляющее соединение FTP
2. **Порты 40000-50000 (TCP)** - пассивный режим передачи данных

### Как открыть порты в Yandex Cloud:

1. Зайдите в консоль Yandex Cloud
2. Перейдите в "Virtual Private Cloud" → "Security Groups"
3. Найдите или создайте Security Group для вашего сервера
4. Добавьте правила:
   - Входящее правило: порт 21, протокол TCP
   - Входящее правило: порты 40000-50000, протокол TCP

## Подключение через FTP клиент

### Настройки для FileZilla / WinSCP / других клиентов:

- **Протокол:** FTP
- **Хост:** 51.250.97.231
- **Порт:** 21
- **Режим:** Пассивный (PASV)
- **Тип входа:** Обычный
- **Пользователь:** <имя_пользователя>
- **Пароль:** <пароль>

### Через командную строку:

```bash
ftp 51.250.97.231
```

## Проверка работы FTP

```bash
# Проверка статуса службы
ssh -i ~/.ssh/mainkey main@51.250.97.231 "sudo systemctl status vsftpd"

# Проверка логов
ssh -i ~/.ssh/mainkey main@51.250.97.231 "sudo tail -f /var/log/vsftpd.log"
```

## Безопасность

- ✅ Анонимный доступ отключен
- ✅ Пользователи ограничены своими домашними директориями (chroot)
- ✅ Включено логирование всех операций
- ✅ Firewall настроен на сервере

## Редактирование конфигурации

Конфигурация находится в `/etc/vsftpd.conf` на сервере.

После изменения конфигурации перезапустите службу:
```bash
ssh -i ~/.ssh/mainkey main@51.250.97.231 "sudo systemctl restart vsftpd"
```
